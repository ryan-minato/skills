# util

[中文](README.zh.md)

Skills that act on the **working process itself** — how the agent and the
user clarify, question, decide, and organize ideas together. They do not
depend on a domain or a tech stack, their product is a shared understanding
rather than files, and they keep their working material in the conversation
instead of your workspace.

```bash
npx skills add ryan-minato/skills --skill <skill-name>
```

Install them per project by default; add `-g` when you want the working
method available in every session.

## Skills

| Skill | Description |
|---|---|
| [clarify-thinking](clarify-thinking/) | Interrogate a plan, an idea, or a decision until agent and user share one understanding: model it as a design tree, ask each round's unblocked questions through the host's own question tool with a recommended answer attached, look every fact up yourself, and leave no files behind. |
