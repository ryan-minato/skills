## Reporting a vulnerability

Please do not report security vulnerabilities through public issues,
discussions, or pull requests.

{{REPORTING_CHANNEL}}

Include as much of the following as you can: the affected version, a
proof of concept or reproduction steps, the impact you expect, and any
suggested mitigation.

## What to expect

- Acknowledgement within {{ACK_SLA}}.
- A fix or mitigation plan communicated within {{FIX_SLA}}.
- Credit in the release notes if you want it — say so in your report.
