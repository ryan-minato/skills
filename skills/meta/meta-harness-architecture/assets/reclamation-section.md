## Periodic Harness Reclamation

At <anchor event / cadence>, sweep the harness for entropy. Last run:
<absolute date>.

1. Run every documented command; fix or remove what fails.
2. Check every path and link; reconnect or delete.
3. Match every section-locating pointer's heading byte-exactly.
4. Hunt duplicated rules; leave one owner.
5. Reconnect or delete anything unreachable from this file.
6. Remove triggers whose subject no longer exists.
7. Thin anything thicker than the project still justifies.

Every finding gets a disposition in the same run — update, reconnect,
merge, thin, or delete — and the run date above is updated.
