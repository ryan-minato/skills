# Harness Reclamation

Runs at <anchor / cadence>. Last run: <absolute date>.

## Sweep

Walk the entrypoint, <architecture document>, every knowledge document,
and every skill:

1. Run every documented command; fix or remove what fails.
2. Check every path and link; reconnect or delete.
3. Match every section-locating pointer's heading byte-exactly.
4. Hunt duplicated rules; leave one owner, point the rest.
5. Flag content unreachable from the entrypoint; reconnect or delete.
6. Flag triggers whose subject no longer exists.
7. Question thickness the project's traits no longer justify.

## Close

Apply or report a disposition for every finding — update, reconnect,
merge, thin, delete. Deleting stale content is success. Record the run
date above.

Done when: every finding has an applied or reported disposition and the
run date is current.
